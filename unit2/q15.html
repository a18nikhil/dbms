Q15. Design SQL Queries to Perform Different Types of Joins (Inner, Left, Right, Full Outer) on Given Tables.

A Join is used to combine related records from two tables based on a common column.

Consider the Following Tables

STUDENT

Student_ID Name
101 Rahul
102 Priya
103 Amit

COURSE

Student_ID Course_Name
101 DBMS
102 Python
104 Java

1. Inner Join

Inner Join returns only the matching records from both tables.

SQL Query:

SELECT STUDENT.Name, COURSE.Course_Name FROM STUDENT INNER JOIN COURSE ON STUDENT.Student_ID = COURSE.Student_ID;

Output:

Name Course_Name
Rahul DBMS
Priya Python

2. Left Join

Left Join returns all records from the left table and matching records from the right table. If no match exists, NULL is displayed.

SQL Query:

SELECT STUDENT.Name, COURSE.Course_Name FROM STUDENT LEFT JOIN COURSE ON STUDENT.Student_ID = COURSE.Student_ID;

Output:

Name Course_Name
Rahul DBMS
Priya Python
Amit NULL

3. Right Join

Right Join returns all records from the right table and matching records from the left table. If no match exists, NULL is displayed.

SQL Query:

SELECT STUDENT.Name, COURSE.Course_Name FROM STUDENT RIGHT JOIN COURSE ON STUDENT.Student_ID = COURSE.Student_ID;

Output:

Name Course_Name
Rahul DBMS
Priya Python
NULL Java

4. Full Outer Join

Full Outer Join returns all records from both tables. If no match exists, NULL is displayed.

SQL Query:

SELECT STUDENT.Name, COURSE.Course_Name FROM STUDENT FULL OUTER JOIN COURSE ON STUDENT.Student_ID = COURSE.Student_ID;

Output:

Name Course_Name
Rahul DBMS
Priya Python
Amit NULL
NULL Java
