Q17. Discuss Nested Subqueries and Joined Relations in SQL with Appropriate Examples.

Nested Subqueries and Joined Relations are used in SQL to retrieve data from one or more tables.

1. Nested Subqueries

A Nested Subquery is a SQL query written inside another query.

The inner query returns a result, which is used by the outer query.

Example: EMPLOYEE Table

Emp_ID Name Salary
101 Rahul 30000
102 Priya 20000
103 Amit 40000

Example: Display employees whose salary is greater than the average salary.

SQL Query:

SELECT Name, Salary FROM EMPLOYEE WHERE Salary > (SELECT AVG(Salary) FROM EMPLOYEE);

Output:

Name Salary
Amit 40000

Explanation:

  • The inner query calculates the average salary, which is 30000.
  • The outer query displays employees whose salary is greater than 30000.

2. Joined Relations

A Joined Relation combines related records from two or more tables using a common column.

Example: Consider the Following Tables

STUDENT

Student_ID Name Dept_ID
101 Rahul D01
102 Priya D02
103 Amit D01

DEPARTMENT

Dept_ID Dept_Name
D01 CS
D02 IT

Example: Display student names along with their department names.

SQL Query:

SELECT STUDENT.Name, DEPARTMENT.Dept_Name FROM STUDENT INNER JOIN DEPARTMENT ON STUDENT.Dept_ID = DEPARTMENT.Dept_ID;

Output:

Name Dept_Name
Rahul CS
Priya IT
Amit CS

Explanation:

  • Dept_ID is the common column in both tables.
  • INNER JOIN combines records where Dept_ID matches.

3. Difference Between Nested Subqueries and Joined Relations

Nested Subqueries Joined Relations
Uses a query inside another query. Combines data from two or more tables.
The inner query provides a result to the outer query. Tables are connected using a common column.
Mainly used to filter records based on another query. Mainly used to display related data from different tables.
