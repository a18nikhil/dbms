UNIT II

Relational Database Model and SQL

Syllabus Topics

Relational Database Model, Logical View of Data, Keys in Relational Database, Integrity Rules, Relational Algebra, Selection, Projection, Join, Division, Relational Calculus, Tuple Relational Calculus, Domain Relational Calculus, Normalization, First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), Boyce-Codd Normal Form (BCNF), SQL, Aggregate Functions, GROUP BY and HAVING Clauses, Null Values, Inner Join, Left Join, Right Join, Full Outer Join, Nested Subqueries, Joined Relations.

Q10 Explain the Logical View of Data and the concept of Keys in a relational database with examples. › Q11 Write SQL queries to demonstrate Selection, Projection, and Join operations on given relational tables. › Q12 Explain the process of Normalization. Discuss 1NF, 2NF, and 3NF with suitable examples. › Q13 Write SQL queries using Aggregate Functions (SUM, AVG, COUNT, MAX, MIN) with GROUP BY and HAVING clauses. › Q14 Discuss the Integrity Rules (Entity Integrity and Referential Integrity) in the relational model. › Q15 Design SQL queries to perform different types of Joins (Inner, Left, Right, Full Outer) on given tables. › Q16 What is BCNF (Boyce-Codd Normal Form)? Explain how it differs from 3NF with an example. › Q17 Discuss Nested Subqueries and Joined Relations in SQL with appropriate examples. › Q19 Discuss Relational Calculus and differentiate between Tuple Relational Calculus and Domain Relational Calculus. › Q21 Explain Aggregate Functions and Null Values in SQL with suitable examples. › Q23 Explain the Selection, Projection, Join, and Division operations in relational algebra with examples. ›
