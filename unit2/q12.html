Q12. Explain the Process of Normalization. Discuss 1NF, 2NF, and 3NF with Suitable Examples.

Normalization is the process of organizing data into smaller, related tables to reduce duplicate data and avoid insertion, update, and deletion problems.

1. First Normal Form (1NF)

A table is in 1NF when each cell contains only one value. A cell should not contain multiple values.

Example: Before 1NF

Student_ID Name Courses
101 Rahul DBMS, Java
102 Priya Python

Here, Rahul has two courses in one cell.

After 1NF

Student_ID Name Course
101 Rahul DBMS
101 Rahul Java
102 Priya Python

Now each cell contains only one value.

2. Second Normal Form (2NF)

A table is in 2NF when:

  • It is already in 1NF.
  • Every non-key column depends on the complete Primary Key, not just part of it.

This removes Partial Dependency.

Example: Before 2NF

Student_ID Course_ID Student_Name
101 C01 Rahul
101 C02 Rahul
102 C01 Priya

Here, the Composite Primary Key is (Student_ID, Course_ID), but Student_Name depends only on Student_ID.

After 2NF

STUDENT

Student_ID Student_Name
101 Rahul
102 Priya

ENROLLMENT

Student_ID Course_ID
101 C01
101 C02
102 C01

Now student names are stored separately, removing Partial Dependency.

3. Third Normal Form (3NF)

A table is in 3NF when:

  • It is already in 2NF.
  • Non-key columns do not depend on other non-key columns.

This removes Transitive Dependency.

Example: Before 3NF

Student_ID Student_Name Dept_ID Dept_Name
101 Rahul D01 CS
102 Priya D02 IT

Here, Student_ID determines Dept_ID, and Dept_ID determines Dept_Name. This is called Transitive Dependency.

After 3NF

STUDENT

Student_ID Student_Name Dept_ID
101 Rahul D01
102 Priya D02

DEPARTMENT

Dept_ID Dept_Name
D01 CS
D02 IT

Now department details are stored separately, removing Transitive Dependency.
