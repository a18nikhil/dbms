Q13. Write SQL Queries Using Aggregate Functions (SUM, AVG, COUNT, MAX, MIN) with GROUP BY and HAVING Clauses.

Aggregate Functions are SQL functions used to perform calculations on multiple rows and return a single result.

1. Consider the Following Table

EMPLOYEE

Emp_ID Name Department Salary
101 Rahul IT 30000
102 Priya HR 25000
103 Amit IT 40000
104 Neha HR 35000
105 Raj IT 50000

2. Aggregate Functions

a) SUM()

Calculates the total of values.

SELECT SUM(Salary) FROM EMPLOYEE;

Output: 180000

b) AVG()

Calculates the average of values.

SELECT AVG(Salary) FROM EMPLOYEE;

Output: 36000

c) COUNT()

Counts the number of rows.

SELECT COUNT(*) FROM EMPLOYEE;

Output: 5

d) MAX()

Finds the highest value.

SELECT MAX(Salary) FROM EMPLOYEE;

Output: 50000

e) MIN()

Finds the lowest value.

SELECT MIN(Salary) FROM EMPLOYEE;

Output: 25000

3. GROUP BY Clause

The GROUP BY clause groups rows having the same value in a column.

Example: Find the total salary of each department.

SQL Query:

SELECT Department, SUM(Salary) AS Total_Salary FROM EMPLOYEE GROUP BY Department;

Output:

Department Total_Salary
IT 120000
HR 60000

4. HAVING Clause

The HAVING clause filters groups based on a condition.

Example: Display departments whose total salary is greater than 70000.

SQL Query:

SELECT Department, SUM(Salary) AS Total_Salary FROM EMPLOYEE GROUP BY Department HAVING SUM(Salary) > 70000;

Output:

Department Total_Salary
IT 120000
