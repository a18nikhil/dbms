Q13. Write SQL Queries Using Aggregate Functions (SUM, AVG, COUNT, MAX, MIN) with GROUP BY and HAVING Clauses.

Aggregate Functions perform calculations on a group of values and return a single result.

Consider the following STUDENT table:

1. SUM()

SUM() calculates the total of numeric values.

Query:

SELECT SUM(Marks) AS Total_Marks FROM STUDENT;

Output:

2. AVG()

AVG() calculates the average of numeric values.

Query:

SELECT AVG(Marks) AS Average_Marks FROM STUDENT;

Output:

3. COUNT()

COUNT() returns the number of records.

Query:

SELECT COUNT(*) AS Total_Students FROM STUDENT;

Output:

4. MAX()

MAX() returns the highest value.

Query:

SELECT MAX(Marks) AS Highest_Marks FROM STUDENT;

Output:

5. MIN()

MIN() returns the lowest value.

Query:

SELECT MIN(Marks) AS Lowest_Marks FROM STUDENT;

Output:

6. GROUP BY Clause

GROUP BY is used to group rows having the same value and apply aggregate functions to each group.

Query:

SELECT Branch, AVG(Marks) AS Avg_Marks FROM STUDENT GROUP BY Branch;

Output:

7. HAVING Clause

HAVING is used to filter groups after GROUP BY based on a condition.

Query:

SELECT Branch, AVG(Marks) AS Avg_Marks FROM STUDENT GROUP BY Branch HAVING AVG(Marks) > 80;
