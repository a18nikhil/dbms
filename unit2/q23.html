Q23. Explain the Selection, Projection, Join, and Division Operations in Relational Algebra with Examples.

Relational Algebra is a procedural query language used to retrieve data from relational databases using different operations.

1. Selection (σ)

Selection is used to retrieve rows from a table that satisfy a given condition.

Syntax:

σcondition(Relation)

Example: STUDENT Table

Student_ID Name Branch
101 Rahul CS
102 Priya IT
103 Amit CS

Query: Display students from the CS branch.

σBranch='CS'(STUDENT)

Output:

Student_ID Name Branch
101 Rahul CS
103 Amit CS

2. Projection (π)

Projection is used to retrieve specific columns from a table. Duplicate rows are removed.

Syntax:

πattributes(Relation)

Example: Display only the names of students.

πName(STUDENT)

Output:

Name
Rahul
Priya
Amit

3. Join (⋈)

Join is used to combine related rows from two tables based on a common attribute.

Syntax:

Relation1 ⋈condition Relation2

Example: ENROLLMENT Table

Student_ID Course
101 DBMS
102 Python
103 Java

Query: Display student names with their courses.

πName,Course (STUDENT ⋈STUDENT.Student_ID=ENROLLMENT.Student_ID ENROLLMENT)

Output:

Name Course
Rahul DBMS
Priya Python
Amit Java

4. Division (÷)

Division is used to find records that are related to all values in another table.

Syntax:

Relation1 ÷ Relation2

Example: ENROLLED Table

Student_ID Course
101 DBMS
101 Python
102 DBMS
103 DBMS
103 Python

REQUIRED_COURSE Table

Course
DBMS
Python

Query: Find students enrolled in all required courses.

ENROLLED ÷ REQUIRED_COURSE

Output:

Student_ID
101
103

Students 101 and 103 are enrolled in both required courses.
