Q21. Explain Aggregate Functions and Null Values in SQL with Suitable Examples.

1. Aggregate Functions in SQL

Aggregate Functions are SQL functions used to perform calculations on multiple rows and return a single result.

Example: EMPLOYEE Table

Emp_ID Name Salary
101 Rahul 30000
102 Priya 20000
103 Amit 40000
104 Neha NULL

a) SUM()

Calculates the total of values.

SELECT SUM(Salary) FROM EMPLOYEE;

Output: 90000

b) AVG()

Calculates the average of values.

SELECT AVG(Salary) FROM EMPLOYEE;

Output: 30000

c) COUNT()

Counts the number of rows.

SELECT COUNT(*) FROM EMPLOYEE;

Output: 4

d) MAX()

Finds the highest value.

SELECT MAX(Salary) FROM EMPLOYEE;

Output: 40000

e) MIN()

Finds the lowest value.

SELECT MIN(Salary) FROM EMPLOYEE;

Output: 20000

2. NULL Values in SQL

A NULL value represents missing, unknown, or unavailable data in a database.

NULL is not the same as zero or an empty string.

Example: In the EMPLOYEE table, Neha's salary is NULL because it is not available.

a) IS NULL

Finds records containing NULL values.

SELECT Name FROM EMPLOYEE WHERE Salary IS NULL;

Output: Neha

b) IS NOT NULL

Finds records without NULL values.

SELECT Name FROM EMPLOYEE WHERE Salary IS NOT NULL;

Output: Rahul, Priya, Amit

3. Effect of NULL on Aggregate Functions

  • SUM(), AVG(), MAX(), and MIN() ignore NULL values.
  • COUNT(*) counts all rows, while COUNT(Salary) counts only non-NULL salary values.

Example: COUNT(*) returns 4, while COUNT(Salary) returns 3.
