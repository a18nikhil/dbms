Q19. Discuss Relational Calculus and Differentiate Between Tuple Relational Calculus and Domain Relational Calculus.

Relational Calculus is a non-procedural query language used to retrieve data from relational databases.

It describes what data is needed, without explaining how to retrieve it.

There are two types of Relational Calculus: Tuple Relational Calculus (TRC) and Domain Relational Calculus (DRC).

1. Tuple Relational Calculus (TRC)

Tuple Relational Calculus uses tuple variables to retrieve data from a table.

A tuple means a complete row in a table.

Syntax:

{t | P(t)}

Where:

  • t represents a row.
  • P(t) represents a condition.

Example: STUDENT Table

Student_ID Name Marks
101 Rahul 80
102 Priya 60
103 Amit 90

Query: Display students whose marks are greater than 70.

{t | t ∈ STUDENT ∧ t.Marks > 70}

Output:

Student_ID Name Marks
101 Rahul 80
103 Amit 90

2. Domain Relational Calculus (DRC)

Domain Relational Calculus uses domain variables to retrieve data from a table.

A domain variable represents an individual attribute value.

Syntax:

{⟨x, y, z⟩ | P(x, y, z)}

Where:

  • x, y, z represent attribute values.
  • P(x, y, z) represents a condition.

Example: Display students whose marks are greater than 70.

{⟨x, y, z⟩ | STUDENT(x, y, z) ∧ z > 70}

Output:

Student_ID Name Marks
101 Rahul 80
103 Amit 90

3. Difference Between TRC and DRC

Tuple Relational Calculus (TRC) Domain Relational Calculus (DRC)
Uses tuple variables. Uses domain variables.
Variables represent complete rows. Variables represent individual attribute values.
Conditions are applied to row attributes. Conditions are applied to individual values.
Syntax: {t | P(t)} Syntax: {⟨x, y, z⟩ | P(x, y, z)}
