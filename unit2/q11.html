Q11. Write SQL Queries to Demonstrate Selection, Projection, and Join Operations on Given Relational Tables.

1. Introduction

Selection, Projection, and Join are relational algebra operations used to retrieve data from relational tables.

  • Selection (σ): Selects rows based on a condition.
  • Projection (π): Selects specific columns.
  • Join (⋈): Combines related records from two tables.

2. Consider the Following Tables

STUDENT

Student_ID Name Branch
101 Rahul CS
102 Priya IT
103 Amit CS

ENROLLMENT

Student_ID Course
101 DBMS
102 Python
103 Java

3. Selection Operation (σ)

Selection retrieves rows that satisfy a given condition.

Example: Display students belonging to the CS branch.

SQL Query:

SELECT * FROM STUDENT WHERE Branch = 'CS';

Output:

Student_ID Name Branch
101 Rahul CS
103 Amit CS

4. Projection Operation (π)

Projection retrieves only the required columns from a table.

Example: Display the names and branches of students.

SQL Query:

SELECT DISTINCT Name, Branch FROM STUDENT;

Output:

Name Branch
Rahul CS
Priya IT
Amit CS

5. Join Operation (⋈)

Join combines related records from two tables using a common attribute.

Example: Display student names along with their enrolled courses.

SQL Query:

SELECT STUDENT.Name, ENROLLMENT.Course FROM STUDENT INNER JOIN ENROLLMENT ON STUDENT.Student_ID = ENROLLMENT.Student_ID;

Output:

Name Course
Rahul DBMS
Priya Python
Amit Java
