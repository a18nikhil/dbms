Q11. Write SQL Queries to Demonstrate Selection, Projection, and Join Operations on Given Relational Tables.

Consider the following two tables:

1. Selection

Selection retrieves specific rows from a table based on a condition.

SQL Query:

SELECT * FROM STUDENT WHERE Branch = 'CS';

Output:

2. Projection

Projection retrieves specific columns from a table.

SQL Query:

SELECT Name, Marks FROM STUDENT;

Output:

3. Join

Join combines related data from two tables using a common attribute.

Here, Student_ID is the common attribute.

SQL Query:

SELECT STUDENT.Name, COURSE.Course_Name FROM STUDENT JOIN COURSE ON STUDENT.Student_ID = COURSE.Student_ID;

This demonstrates that Selection retrieves rows, Projection retrieves columns, and Join combines related data from two tables.
