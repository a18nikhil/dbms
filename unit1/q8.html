Q8. What are Data Models? Discuss the Evolution of Data Models from Hierarchical to Relational and Object-Oriented Models.

1. Meaning of Data Model

A data model is a collection of concepts and notations used to describe:

  • Data
  • Relationships between data
  • Constraints on data

It provides a common language for database designers, developers, and users to understand how data is organized.

2. Evolution of Data Models

Data models evolved over time to handle increasingly complex data and requirements.

3. Major Data Models

  1. File-Based Model
    Used in the early 1960s.
    Data was stored in separate files.
    Managing relationships between files was difficult.
  2. Hierarchical Model
    Developed during the 1960s–1970s.
    Organizes data in a tree-like structure.
    Supports parent-child relationships.
    One parent can have many children.
  3. Network Model
    Developed during the 1960s–1970s.
    Represents data using a network of relationships.
    Supports more complex relationships than the hierarchical model.
  4. Relational Model
    Introduced by E. F. Codd in 1970.
    Organizes data into tables consisting of rows and columns.
    Uses keys and relationships to connect tables.
    Became the dominant traditional database model.
  5. Object-Oriented Model
    Became important during the 1980s–1990s.
    Represents data as objects, combining data and behavior.
    Useful for complex data and object-oriented applications.
