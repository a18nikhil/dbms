Q8. What are Data Models? Discuss the Evolution of Data Models from Hierarchical to Relational and Object-Oriented Models.

1. Meaning of Data Model

A Data Model is a collection of concepts used to describe how data is organized, stored, and related in a database.

It describes three main things:

  • Data: Information stored in the database.
  • Relationships: Connections between different data.
  • Constraints: Rules that control the data.

Data models help database designers understand and organize data properly.

2. Evolution of Data Models

Data models have changed over time to organize and manage data more easily.

3. Major Data Models

1. File-Based Model

  • Used in the early 1960s.
  • Data was stored in separate files.
  • Managing relationships between files was difficult.
  • It often caused data duplication and inconsistency.

Example: Student information stored in separate files.

2. Hierarchical Model

  • Developed during the 1960s–1970s.
  • Organizes data in a tree-like structure.
  • Each child record has only one parent.
  • Supports One-to-Many (1:N) relationships.

Example: One department has many students.

3. Network Model

  • Developed during the 1960s–1970s.
  • Organizes data using a network of connected records.
  • A child record can have multiple parents.
  • Supports Many-to-Many (M:N) relationships.

Example: A student can enroll in many courses, and each course can have many students.

4. Relational Model

  • Introduced by E. F. Codd in 1970.
  • Organizes data into tables containing rows and columns.
  • Uses Primary Keys and Foreign Keys to connect tables.
  • SQL is used to store, retrieve, and manage data.

Example: STUDENT and ENROLLMENT tables connected using Student_ID.

5. Object-Oriented Model

  • Became important during the 1980s–1990s.
  • Stores data in the form of objects.
  • Objects contain both data (attributes) and operations (methods).
  • Useful for handling complex data and object-oriented applications.

Example: A STUDENT object contains Student_ID, Name, and a ViewMarks() method.
