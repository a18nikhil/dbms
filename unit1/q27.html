Q27. Discuss the Degrees of Abstraction in a Database System with a Neat Diagram.

1. Introduction

Degrees of Data Abstraction describe how data is represented at different levels, from its actual storage to the way users understand it.

There are three degrees of data abstraction:

  • Low-Level / Physical Model
  • Representational / Logical Model
  • High-Level / Conceptual Model

2. Diagram: Degrees of Data Abstraction

3. Degrees of Data Abstraction

1. Low-Level / Physical Model

  • It is the lowest level of data abstraction.
  • It describes how data is actually stored on disk.
  • It includes files, indexes, and storage structures.

Example: Student marks stored in a disk file using a B+-tree index.

2. Representational / Logical Model

  • It is the middle level of data abstraction.
  • It describes how data is organized in a DBMS.
  • It represents data using tables, columns, and relationships.
  • It hides physical storage details.

Example: A STUDENT_MARKS table containing Student_ID, Course_ID, and Marks.

3. High-Level / Conceptual Model

  • It is the highest level of data abstraction.
  • It describes data as users understand it.
  • It focuses on entities, attributes, and relationships.
  • It is represented using ER Diagrams and UML Class Diagrams.

Example: A student receives marks in different courses.
