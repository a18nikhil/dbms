Q3. Assess the Concept of Relational Databases and Their Key Characteristics.

A Relational Database stores data in the form of tables. Each table contains rows and columns. The relational model was introduced by E. F. Codd in 1970.

Example of Relational Database

Key Characteristics

1. Table-Based Structure

Data is organized into tables containing rows and columns.

Example: STUDENT table.

2. Relation

A table in a relational database is called a relation.

Example: STUDENT table is a relation.

3. Tuple

A row in a table is called a tuple or record.

Example: (101, Rahul, B.Sc. CS, 8.2) is one tuple.

4. Attribute

A column in a table is called an attribute or field.

Example: Student_ID, Name, Program, and CGPA are attributes.

5. Domain

A domain specifies the set of allowed values or data type of an attribute.

Example: CGPA contains numerical values, usually between 0 and 10.

6. Keys

Keys are used to uniquely identify records and establish relationships between tables.

  • Primary Key: Uniquely identifies each record. Example: Student_ID is the primary key of the STUDENT table.
  • Foreign Key: An attribute that refers to the primary key of another table.

7. Degree

The number of columns in a relation is called its degree.

Example: Degree = 4 (Student_ID, Name, Program, CGPA).

8. Cardinality

The number of rows in a relation is called its cardinality.

Example: Cardinality = 3 because the STUDENT table contains three student records.
